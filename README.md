## À propos

**Art-Jatie Boutique** est une plateforme e-commerce complète dédiée à l'artisanat crochet malgache, avec un agent IA conversationnel intégré (**Jatie**) pour accompagner les clients en temps réel.

---

## Fonctionnalités

- 🛍️ Catalogue produits avec recherche sémantique (pgvector)
- 🤖 Agent IA **Jatie** — chatbot multilingue FR/MG avec routing intelligent
- 📦 Gestion de commandes personnalisées
- 📊 Dashboard admin avec statistiques en temps réel
- 💳 Paiement Mobile Money intégré
- 🌍 Support AI multilingue Français / Malagasy

---

## Stack technique

| Couche | Technologie |
|---|---|
| Frontend | Next.js · TypeScript · Tailwind CSS |
| Backend | FastAPI · Python |
| Base de données | PostgreSQL + pgvector |
| IA | Multi-agent LLM · Embeddings Jina v3 |
| Infrastructure | Docker · Traefik · Contabo VPS |
| CI/CD | GitHub Actions · GitHub Container Registry |
| Déploiement frontend | Vercel |
